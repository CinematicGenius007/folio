# Themes and backgrounds

Open the Folio menu with `O`, or press `B` for background settings.

## Themes

| Theme    | Feel                                       |
| -------- | ------------------------------------------ |
| Overcast | Cool, near-white ground with charcoal text |
| Dusk     | Lifted charcoal, never pure black          |
| System   | Follows your operating system              |

## Backgrounds

Backgrounds are drawn on your device, not downloaded. All of them keep the middle of the page calm, where your list is, and let the edges carry the mood.

| Background                  | What it looks like                                                                                            |
| --------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Marble                      | Soft halftone dots in a marbled pattern, faded behind the list                                                |
| Meadow                      | A quiet dusk meadow: navy sky and a coral cloud along the top, a green hill along the bottom, with film grain |
| Edges, Glow, Horizon, Waves | Fine dithered patterns in the side margins                                                                    |
| Image                       | Your own picture, dimmed so text stays readable                                                               |
| None                        | A plain page                                                                                                  |

Each one has three strengths: **soft**, **medium** and **strong**. A picture you choose is stored locally in your browser profile and never uploaded.

## Site icons

On Chromium browsers Folio shows the icons your browser already has cached. Sites you have never visited get a letter tile in a stable colour. On Firefox and Zen, Folio fetches each site's own icon once and caches it; see [Privacy](/docs/privacy) for exactly how.
